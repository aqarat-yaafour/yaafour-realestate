# موقع مطعم الفلافل + منيو QR

- الصفحة الرئيسية: `index.html`
- صفحة المنيو (يوجّه إليها الـ QR): `menu/` ← الرابط النهائي سيكون `https://دومينك/menu/`
- **كل الأصناف والأسعار في ملف واحد فقط:** `data/menu.json`

## تعديل سعر أو صنف (من الجوال أو الكمبيوتر)

1. افتح المستودع على GitHub ← `falafel-restaurant/data/menu.json` ← أيقونة القلم ✏️.
2. عدّل ما تريد (أمثلة بالأسفل).
3. اضغط **Commit changes**. سيظهر التعديل على الموقع خلال دقيقة أو اثنتين.

### أمثلة

تغيير السعر — غيّر الرقم فقط، **بدون** علامات تنصيص وبدون كتابة العملة:
```json
"price": 7,
```

صنف انتهى مؤقتًا — لا تحذفه، فقط غيّر:
```json
"available": false
```

صنف بأحجام — استخدم `sizes` بدل `price`:
```json
"sizes": [
  { "label": "عادي", "price": 5 },
  { "label": "كبير", "price": 8 }
]
```

إضافة صنف جديد — انسخ صنفًا موجودًا كاملًا من `{` إلى `}`، والصقه بعده، وضع فاصلة `,` بينهما، ثم غيّر:
- `id`: اسم إنجليزي قصير **فريد** بدون مسافات (مثل `"shawarma-plate"`) ولا تغيّره بعد ذلك.
- `category`: يجب أن يطابق `id` أحد التصنيفات في أعلى الملف.

### أخطاء شائعة
- فاصلة ناقصة بين صنفين، أو فاصلة زائدة بعد آخر صنف ← المنيو كلها لن تظهر.
- كتابة السعر كنص `"7"` أو `"7 ريال"` ← خطأ. الصحيح: `7`.

## الطلب عبر واتساب (السلة)
- يضيف الزبون الأصناف (بالحجم المطلوب) والإضافات، ثم يضغط «أرسل عبر واتساب» فتفتح المحادثة برسالة جاهزة فيها الأصناف والكميات والإجمالي.
- **لا تظهر أزرار الطلب إلا بعد وضع رقم واتساب صالح** في `restaurant.whatsapp`: نص من 8 إلى 15 رقمًا بالصيغة الدولية، بدون `+` ولا أصفار بادئة، مثل `"9665XXXXXXXX"`.
- الصنف `available: false` لا يمكن طلبه.
- كل **إضافة** في `extras` يجب أن يكون لها `id` فريد (مثل `"extra-cheese"`).
- السلة تُحفظ في جوال الزبون؛ إذا غيّرتَ سعرًا يظهر السعر الجديد تلقائيًا، وإذا حذفتَ صنفًا يُزال من سلته.

## بيانات الصفحة الرئيسية
كلها في `restaurant` داخل `menu.json`، وأي زر بلا بيانات يختفي تلقائيًا:
- `schedule`: ساعات الدوام لشارة «مفتوح الآن / مغلق»، مثل `{ "open": "06:00", "close": "24:00" }`. الدوام الذي يعبر منتصف الليل يُكتب هكذا: `{ "open": "18:00", "close": "02:00" }`. (نفس الساعات كل الأيام.)
- `timezone`: منطقة المطعم مثل `"Asia/Riyadh"`؛ الشارة تُحسب بها لا بساعة جوال الزبون.
- `phone`: أرقام فقط (يمكن أن يبدأ بـ `+`) ← يظهر زر «اتصل بنا».
- `mapsUrl`: رابط خرائط يبدأ بـ `https://` ← يظهر زر «الموقع على الخريطة». و`address` نص العنوان.
- `hours` نص للعرض فقط؛ الشارة تعتمد على `schedule`.

## معاينة المشاركة (واتساب) والنطاق
- صورة المعاينة `assets/img/og.png` (1200×630) والأيقونات في `assets/img/`. استبدلها بشعار مطعمك؛ **واتساب يحفظ المعاينة مؤقتًا، فإذا غيّرتَ الصورة استخدم اسم ملف جديدًا** وحدّث `og:image`.
- وسوم المعاينة تحتاج **رابطًا مطلقًا**. بعد ربط النطاق النهائي شغّل مرة واحدة:
  ```bash
  node tools/set-domain.mjs https://دومينك.com
  ```
  فيُحدَّث `index.html` و`menu/index.html` و`robots.txt` و`sitemap.xml`.
- اسم المطعم والوصف في `<title>` ووسوم `og:` و`manifest.webmanifest` **ثابتة** (لا تُقرأ من `menu.json`)؛ عدّلها يدويًا إذا غيّرتَ الاسم.
- `_headers` يضبط التخزين المؤقت (بيانات المنيو `no-cache`) وترويسات الأمان على Cloudflare Pages.

## فحص الملف قبل النشر (اختياري)
```bash
node tools/validate-menu.mjs   # فحص المنيو (يحذّر إن كان رقم واتساب فارغًا)
node tools/test-order.mjs      # اختبار منطق السلة والرسالة
node tools/test-hours.mjs      # اختبار مفتوح/مغلق
```

## التجربة على الكمبيوتر
فتح الملف مباشرة بالنقر المزدوج **لن يعمل** (المتصفح يمنع قراءة `menu.json`). شغّل خادمًا محليًا:
```bash
cd falafel-restaurant
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000/menu/`.

## الاستضافة (Cloudflare Pages)
- Build command: فارغ
- Build output directory: `falafel-restaurant`

## ما يزال مطلوبًا من صاحب المطعم
البيانات الحالية في `menu.json` **أمثلة مؤقتة**. يجب استبدال:
- اسم المطعم، العملة، ساعات العمل
- `whatsapp`: الرقم بالصيغة الدولية بدون + أو أصفار (مثل `9665XXXXXXXX`) — **بدونه لا يعمل الطلب** وتختفي أزرار الإضافة
- الأصناف والأسعار الحقيقية
